## Вариант 15

### Условие задачи

Написать программу, которая по введенному возрасту ребенка в месяцах выводит возрастную категорию:

- новорожденный — до 2 месяцев;
- младенец — до 1 года;
- раннее детство — 1–3 года;
- дошкольник — 3–7 лет;
- школьник — 7–13 лет;
- подросток — 13–17 лет.

Для проверки границ возраст переводится в месяцы:

- 1 год = 12 месяцев;
- 3 года = 36 месяцев;
- 7 лет = 84 месяца;
- 13 лет = 156 месяцев;
- категория 13–17 лет охватывает возраст до наступления 18 лет, то есть до 216 месяцев.
